# CLI Contract

프로젝트의 실행 명령은 `jpick`으로 정한다. 설치 후 터미널에서 실행하며,
개발 환경에서는 `uv run jpick ...`를 사용한다.

## 명령

```text
jpick list [FILTERS] [--sort id|difficulty|rate|solvers|random] [--order asc|desc] [--limit N]
jpick recommend [FILTERS] [--count N]
jpick open ID [ID ...]
jpick --help
jpick --version
```

버전은 설치한 프로젝트 메타데이터에서 읽는다.
각 하위 명령도 `--help`를 제공하며, tier 1=Bronze V부터 30=Ruby I까지의 순서를 설명한다.

## 공통 필터

| 옵션 | 형식·기본값 |
| --- | --- |
| --min-tier / --max-tier | 정수 1~30. 기본은 제한 없음 |
| --min-rate / --max-rate | 소수 0~100. % 기호 없이 입력. 기본은 제한 없음 |
| --min-solvers / --max-solvers | 정수 0 이상. 기본은 제한 없음 |
| --status | all / solved / unsolved. 기본 all |
| --user | 공개 사용자 핸들. @ 접두사는 허용. solved/unsolved에서 필수 |

모든 범위는 양 끝을 포함한다. 잘못된 범위와 NaN·Infinity는 입력 오류다.
`--status all --user NAME`은 불필요한 사용자 지정임을 알리고 입력 오류로 처리한다.
사용자 핸들은 정확히 일치하는 계정으로 해석하며 대소문자를 임의 변경하지 않는다.

## list

기본은 `--sort id --order asc --limit 20`이다.
limit은 양의 정수이며 전체 후보 범위를 줄이지 않는다.
random은 전체 고유 적격 후보를 섞는 옵션이다. random과 order=desc 조합은 입력 오류다.
ID 동점은 존재하지 않으며, 지표 동점과 미확인 그룹은 ID 오름차순을 유지한다.

stdout에 번호·제목·난이도·정답률·푼 사람 수·문제 링크를 표시한다.
요약에는 적용 조건, 전체 적격 개수, 실제 표시 개수와 조회 시각을 포함한다.
풀이 조건을 사용하면 기준 사용자와 solved/unsolved도 포함한다.
명시적으로 미제공인 값은 '미확인', 난이도 미정은 '미정'으로 표시한다.

## recommend

count 기본값은 1이며 양의 정수다. 필터는 list와 의미가 동일하다.
전체 고유 적격 후보에서 min(count, eligible_count)개를 균등하게 비복원 추출한다.
결과의 열은 list와 같고, 요청·실제 반환 개수 및 부족 개수를 표시한다.
후보 0개와 후보 부족은 성공이다. 조회 실패는 추천 부족으로 바꾸지 않는다.

## open

양의 정수 문제 번호를 한 개 이상 받는다. 입력 순서를 유지하며 중복 번호를 제거한다.
각 번호의 `https://jungol.co.kr/problem/<ID>`를 기본 브라우저에 한 번씩 전달한다.
원격 조회·Chromium 실행·사이트 로그인 없이 표준 webbrowser 기능을 사용한다.
브라우저 전달 성공은 페이지 존재나 로딩 완료의 보장은 아니다.
실패해도 직접 열 수 있도록 모든 요청 링크와 실패 번호를 출력한다.
일부만 열렸다면 실패 종료하며 이미 열린 탭을 다시 열지 않는다.

list와 recommend는 기본 브라우저를 열지 않는다.
데이터 조회용 비영구 Chromium은 화면에 표시하지 않는다.

## 진행·실패·종료

stdout은 결과 표·요약·직접 열기 링크에 사용한다.
stderr는 조회 진행과 미제공 지표 제외 안내, 오류 원인에 사용한다.
진행에는 현재 단계와 수집·상세 확인 개수, Ctrl+C 취소 방법을 표시한다.
총 페이지 수를 모르면 완료율이나 남은 시간을 만들어 표시하지 않는다.

| 코드 | 의미 |
| --- | --- |
| 0 | 완전한 성공. 정상 빈 결과와 후보 부족 포함 |
| 1 | 네트워크·접근·사용자 확인·DOM 계약·브라우저 열기 실패 |
| 2 | 잘못된 옵션·범위·개수·사용자 누락 |
| 130 | 사용자의 Ctrl+C 취소 |

수집 중 실패하면 최종 문제 표나 추천 결과를 출력하지 않는다.
원인과 직접 할 수 있는 다음 행동(입력 수정·접속 상태 확인 등)을 안내한다.
JSON 출력·표 파이프 입력·설정 파일·결과 파일 저장은 이번 계약에 추가하지 않는다.
